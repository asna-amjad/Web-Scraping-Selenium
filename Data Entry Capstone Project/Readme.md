# Data Entry Job Automation (Web Scraping Capstone Project)

### Concepts Practiced: 
* Web scraping using BeautifulSoup
* Handling dynamic property listings from web pages
* Data cleaning (removing symbols, formatting text, splitting strings)
* Automating browser tasks using Selenium WebDriver
* Locating elements using XPath, CSS Selectors, and LINK_TEXT
* Automating Google form filling and sumbit response using Selenium
* Handling multi-step form submissions
* Browser automation with ChromeOptions
* Combining Requests and Selenium workflow
* Basic ETL pipeline (Extract → Transform → Load into form)
